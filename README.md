# Аніме каталог

Односторінковий застосунок (HTML, CSS і JS без бекенду) для ведення особистого каталогу аніме: статуси перегляду, серії, оцінки, категорії, студії озвучки, франшизи, статистика. Встановлюється як справжній застосунок (PWA) на телефон і ПК.

## Файли, які потрібно завантажити на хостинг

Завантажте **всі чотири файли** в корінь репозиторію (без цього іконки/встановлення не запрацюють):

- `index.html` — сам застосунок
- `manifest.json` — опис застосунку для встановлення (назва, іконки, колір)
- `service-worker.js` — вмикає можливість встановлення й офлайн-роботу
- `icon-192.png`, `icon-512.png` — іконки застосунку

## Як розмістити на GitHub Pages

1. Створіть новий репозиторій на GitHub.
2. Завантажте всі файли вище в корінь репозиторію (**Add file → Upload files**).
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → **Save**.
4. Через 1–2 хвилини сайт буде доступний за адресою:
   ```
   https://<ваш-логін>.github.io/<назва-репозиторію>/
   ```

GitHub Pages віддає сайт по HTTPS автоматично — це обов'язкова умова для роботи service worker і встановлення застосунку.

## Встановлення як застосунок

Після розгортання на GitHub Pages (або будь-якому хостингу з HTTPS):

- **Android (Chrome):** з'явиться банер «Встановити застосунок», або меню ⋮ → «Встановити застосунок» / «Додати на головний екран». Можна також натиснути кнопку **«Встановити на головний екран»** в Налаштуваннях застосунку.
- **iPhone/iPad (Safari):** кнопка «Поділитися» → «На екран «Домой»».
- **ПК (Chrome/Edge):** іконка встановлення (⊕ або монітор) праворуч в адресному рядку, або кнопка в Налаштуваннях застосунку.

Після встановлення застосунок відкривається окремим вікном без адресного рядка браузера, отримує власну іконку на головному екрані/в меню застосунків, і навіть частково працює офлайн (уже відкрита сторінка залишається доступною без інтернету).

⚠️ Встановлення й service worker працюють **тільки при доступі по HTTPS** (GitHub Pages це забезпечує автоматично) — якщо просто відкрити `index.html` подвійним кліком з диска (`file://`), сама сторінка працюватиме повністю, але кнопка встановлення й офлайн-кеш будуть недоступні.

## Збереження даних

Застосунок автоматично зберігає всі дані (тайтли, постери, категорії, студії, франшизи) у **`localStorage`** браузера — прямо на пристрої, без будь-якого сервера чи акаунта. Це означає:

- Дані зберігаються між сеансами **в тому самому браузері на тому самому пристрої** (включно з встановленим як застосунок варіантом — це той самий браузерний рушій).
- Якщо очистити дані сайту в браузері (кеш/cookies/"дані сайтів") — каталог теж очиститься.
- Дані **не синхронізуються** між різними пристроями чи браузерами автоматично.
- Щоб перенести дані на інший пристрій або зробити резервну копію — використовуйте кнопку **«Завантажити бекап (.json)»** в Налаштуваннях застосунку, а на новому пристрої — **«Відновити з бекапу»**.

Рекомендується періодично робити бекап, особливо якщо в каталозі багато тайтлів із завантаженими постерами (великі зображення швидше наближають до ліміту сховища браузера, зазвичай ~5–10 МБ).

## Локальний запуск без GitHub

Файл `index.html` можна просто відкрити подвійним кліком у будь-якому сучасному браузері — інтернет для роботи не потрібен (крім необов'язкового підвантаження шрифту Google Fonts). Кнопка встановлення застосунку в цьому режимі не працюватиме (див. застереження вище) — для цього потрібен реальний хостинг по HTTPS.

## Структура файлів

- `index.html` — увесь застосунок
- `manifest.json` — маніфест PWA
- `service-worker.js` — service worker для встановлення й офлайн-кешу
- `icon-192.png`, `icon-512.png` — іконки застосунку
- `README.md` — цей файл
